# Nsi-legend-of-grimrock
Bonjour Paris By Night est un jeu inspiré de Legend Of Grimrock, dans notre jeu, vous atterissez dans les catacombes, seul avec votre équipe face à d'inombrables monstres, fuyez.
pour ce jeu vous aurez besoin d'installer Pygame et pytmx
les touches principales: 
zqsd, pour les déplacements
e pour intéragir
f pour l'inventaire
tab pour le menu pause 
g pour jeter un objet
pour attaquer vous devez cliquer sur un personnage
pour donner un objet a un personnages selectionnée l'objet puis le personnage
Vous en savez désormais autant que moi, vous pouvez y aller.
